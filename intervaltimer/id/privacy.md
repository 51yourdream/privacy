# Kebijakan Privasi Interval Timer

**Terakhir diperbarui: 15 Oktober 2026**

Interval Timer (“Aplikasi”) adalah pengatur waktu interval untuk iPhone dan Apple Watch. Tidak perlu akun. Kami tidak menjalankan server untuk aplikasi ini dan tidak memakai SDK analitik atau iklan.

Aplikasi tidak mengumpulkan nama, email, telepon, foto, kamera, mikrofon, kontak, lokasi, data kesehatan, IDFA, atau analitik penggunaan. Panduan suara dibuat di perangkat; kami tidak merekam atau mengunggahnya.

Hanya disimpan di perangkat, tidak dikirim kepada kami: rutinitas yang Anda buat (nama, durasi, suara, dan struktur, termasuk pemanasan, pendinginan, EMOM, dan ronde yang lebih lama), sesi yang selesai, kulit, bahasa, suara, panduan suara, target mingguan, apakah pengenalan selesai, dan salinan status langganan di perangkat.

Jika Anda mengizinkan notifikasi, Aplikasi dapat menjadwalkan notifikasi lokal saat satu fase akan berakhir. Notifikasi bisa dimatikan di Pengaturan iOS. Pengatur waktu tetap berjalan saat Aplikasi terbuka.

Apple Watch menerima daftar rutinitas, bahasa, kulit, dan status langganan dari iPhone, serta dapat mengirim kembali sesi yang selesai. Ini tetap di antara perangkat Anda. Kami tidak menerima data itu.

Pembayaran diproses Apple lewat Apple ID. Kami tidak melihat kartu. Apple: https://www.apple.com/legal/privacy/ RevenueCat memberitahu apakah langganan aktif dan menerima pengenal anonim, tanda terima, status langganan, versi aplikasi, sistem operasi, dan negara App Store. Ini tidak terhubung ke nama Anda. RevenueCat: https://www.revenuecat.com/privacy Kelola atau batalkan di Pengaturan → Apple ID → Langganan. Aplikasi tidak memiliki layar pengelolaan. Ketentuan: https://www.apple.com/legal/internet-services/itunes/dev/stdeula/

Data di perangkat hanya untuk pengatur waktu, rutinitas, riwayat, suara, target mingguan, dan fitur berbayar. Kami tidak menjual data pribadi dan tidak memakainya untuk iklan.

Aplikasi tidak ditujukan untuk anak di bawah 13 tahun. Kami tidak dengan sengaja mengumpulkan data pribadi anak.

Data berada di penyimpanan privat Aplikasi. Sambungan ke Apple dan RevenueCat memakai HTTPS. Data tetap ada sampai Anda menghapus Aplikasi. Catatan langganan disimpan Apple dan RevenueCat menurut kebijakan mereka.

Anda dapat mengubah notifikasi, bahasa, suara, dan target di Aplikasi atau iOS, menghapus Aplikasi, atau meminta kami agar RevenueCat menghapus catatan pembelian anonim.
