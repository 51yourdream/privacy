# Interval Timer プライバシーポリシー

**最終更新日：2026年10月15日**

Interval Timer（「本アプリ」）は、iPhone と Apple Watch 向けのインターバルタイマーです。アカウントは不要です。このアプリ用のサーバーは運営しておらず、分析や広告の SDK も使いません。

本アプリは、氏名、メール、電話番号、写真、カメラ、マイク、連絡先、位置情報、ヘルスケアのデータ、IDFA、利用分析を収集しません。音声ガイドは端末上で作られ、録音も送信もしません。

端末だけに保存し、当社には送らないもの：作成したプラン（名前、時間、音、ウォームアップ、クールダウン、EMOM、セットごとの延長を含む構成）、完了したセッション、スキン、言語、音、音声ガイド、週間目標、初回案内を終えたか、サブスクリプション状態のキャッシュ。

通知を許可すると、区間の終わりにローカル通知を出せます。iOS の設定で消せます。拒否しても、アプリを開いているあいだタイマーは動きます。

Apple Watch は、iPhone からプラン一覧、言語、スキン、サブスクリプション状態を受け取り、完了したセッションを iPhone に返せます。お客様の端末間の通信であり、当社は受け取りません。

支払いは Apple ID を通じて Apple が処理します。カード番号は届きません。Apple：https://www.apple.com/legal/privacy/ RevenueCat はサブスクリプションが有効かを伝え、端末で作られた匿名の識別子、レシート、状態、アプリの版、OS、App Store の国を受け取ります。氏名とは結び付きません。RevenueCat：https://www.revenuecat.com/privacy 管理や解約は設定の Apple ID → サブスクリプションで行います。アプリ内に管理画面はありません。利用規約：https://www.apple.com/legal/internet-services/itunes/dev/stdeula/

端末上のデータは、タイマー、プラン、履歴、音声、週間目標、有料機能のためだけに使います。個人情報を販売せず、広告にも使いません。

本アプリは 13 歳未満の子どもを対象にしていません。子どもの個人情報を故意に収集しません。

データはアプリの私有領域にあり、Apple と RevenueCat との通信は HTTPS です。アプリを削除するまで残ります。サブスクリプションの記録は Apple と RevenueCat が各自の方針で保管します。

通知、言語、音、週間目標はアプリまたは iOS の設定で変えられます。アプリを削除するか、RevenueCat にある匿名の購入記録の削除を当社に依頼できます。
